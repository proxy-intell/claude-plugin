---
name: ad-script-writer
description: Write short-form video ad scripts (TikTok, Reels, Shorts, Meta video). Use when the user wants a script, hook variants, or a UGC brief, optionally modeled on a competitor's video ad.
---

If the user points at a competitor's video ad, run `analyze_ad_video` first (use `tiktok_id` for TikTok ads) to get the transcript and scene structure. Credits are a daily budget; analyze one or two ads, not a dozen.

1. Get the product, audience, offer and length (default 30s). Ask once if missing.
2. Break down the reference ad if given: hook, problem, proof, offer, CTA, and timing of each beat.
3. Write 3 script variants. Do not copy the competitor's wording; reuse the structure, change the angle.
4. Use this format per script:

| Time | Visual | Voiceover / on-screen text |
|------|--------|----------------------------|

5. Each script has: a hook in the first 3 seconds, one clear claim, proof, and one CTA.
6. Add 3 alternate hooks the user can swap in for testing.

Keep claims truthful and checkable; flag any claim the user must substantiate before running the ad.
