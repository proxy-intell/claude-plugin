---
name: creative-strategy
description: Turn competitor ads into a creative strategy. Use when the user wants ad angles, hooks, a creative brief, or test ideas for their own product based on what competitors run.
---

Credits are a daily budget. Analyze only the ads that matter; image and video analysis cost 1 credit each. Never state plan limits.

1. Get the user's product, audience and goal. If missing, ask once, briefly.
2. Pull 2-4 competitors' ads (see the competitor-research skill). Prefer the longest-running ads.
3. Analyze the best 3-6 creatives: `analyze_ad_image` for images, `analyze_ad_video` for video (it also transcribes the voiceover).
4. Map what you found: angles (price, proof, pain, speed, identity), hooks, formats, offers, CTAs. Note which angles are crowded and which are open.
5. Deliver a brief:
   - 3 angles to test, each with the audience insight behind it
   - 2 hooks per angle
   - Format recommendation per angle (UGC, static, demo, testimonial)
   - What to avoid because competitors saturate it
   - A simple test plan: one variable per test

Cite the competitor ads that informed each angle. Mark inferences as inferences.
